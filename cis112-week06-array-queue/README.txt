Queues and Queues Using Arrays in Java -- six Beamer decks
==========================================================

queue-0-concepts    queue-concepts.tex    FIFO, the queue ADT, two indices and a circular array,
                                           enqueue/dequeue/peek, overflow, growing and unwrapping,
                                           cost, applications (printer, BFS, buffers), Java classes
queue-1-freshman    queue-freshman.tex    install, IntQueue step by step, tracing on paper,
                                           an interactive queue, five common mistakes with their
                                           real error messages, compiler errors
queue-2-sophomore   queue-sophomore.tex   interface + generic ArrayQueue<T>, iterator, generic
                                           arrays, growing/shrinking, loitering, tests (and JUnit),
                                           Queue/Deque methods
queue-3-junior      queue-junior.tex      linked vs circular array, boxing, a benchmark, bytes per
                                           element, cache locality, copies and the potential method,
                                           BFS, producer/consumer, thread pools, blocking
queue-4-senior      queue-senior.tex      ArrayDeque internals (javap), power-of-two arithmetic,
                                           ring buffers, Michael--Scott lock-free queue, ABA,
                                           memory ordering, bounded vs unbounded, back-pressure,
                                           scheduling, SequencedCollection, API lessons
queue-5-examples    queue-examples.tex    real programs: IntQueue, ArrayQueue<T>, printer, BFS,
                                           Josephus, palindrome, hot potato, sliding maximum,
                                           ArrayDeque, PriorityQueue

hblib/ is shared: ../../hblib/hblibPresentation.sty, hblibCodeoutput.sty,
hblibDatastructures.sty.  The queue decks use \hQueueArray{capacity}{head}{tail}{size}{elements}
from hblibDatastructures.sty: it draws the queue in the circular array in QUEUE order, so a
wrapped queue is shown correctly (the older \hQueue draws elements from index 0 only).

Building a deck (Windows: Command Prompt; macOS: Terminal)
---------------------------------------------------------
  cd queue-0-concepts
  pdflatex queue-concepts.tex       (twice, for i/N and the outline)
  pdflatex queue-concepts.tex

Programs and their outputs
--------------------------
Every output on the slides is REAL (JDK 24 in this build):
  codeoutput/<Name>.java     a program; classes without main() (IntQueue, ArrayQueue, LinkedQueue,
                             QueueADT, MsQueue, ...) are only compiled
  codeoutput/<Name>.in       its keyboard input, .args its arguments, .jvmargs its JVM options
  codeoutput/<Name>.sh       a terminal session, run in a copy of codeoutput/<Name>/
  codeoutput/<Name>.txt      what it printed, regenerated by:   bash run_examples.sh  [Name.java]
                             (macOS: Terminal; Windows: Git Bash)

Timings (the benchmark, producer/consumer, Michael--Scott), the number of arrays before
OutOfMemoryError, and the BFS times change from run to run. The slides only claim what held in
every run; the junior deck says "one run on this machine" where it shows a table of times.
JUnit and JMH listings are marked "Not run here".
